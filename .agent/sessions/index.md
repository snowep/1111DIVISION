# Session Index

## Purpose

Record of work sessions for continuity across restarts. Lightweight log of what was done, decided, and what's next.

---

## Structure

```
sessions/
├── YYYY-MM-DD-session-N.md
└── index.md          # This file
```

```markdown
YYYY-MM-DD

<list>

## Work Done

- <task>: <result>
- <task>: <result>

## Decisions Made

- <decision>: <rationale>

## Blockers / Open Questions

- <issue>

## Next Actions

- [ ] <action>
- [ ] <action>

## Notes

<free-form observations>
```
