# ORION Evolution

## Purpose

Controlled self-improvement through evidence-based proposals.

## Pipeline

```
OBSERVE PROBLEM
      ↓
COLLECT EVIDENCE
      ↓
PROPOSE CHANGE
      ↓
TEST
      ↓
EVALUATE
      ↓
ACCEPT / REJECT
      ↓
VERSION
```

## Rules

1. Evolution proposals are never auto-applied.
2. Every proposal needs evidence.
3. Every proposal needs a test plan.
4. Acceptance requires evaluation.
5. Accepted changes are versioned.

## Files

- `engine.py` — EvolutionEngine, EvolutionProposal, EvolutionStatus
- `version.py` — Semantic version helper
