# File Restructuring

Status: ACTIVE
Learned: 2026-09-10

## What JARVIS Learned

1. Audit all files first — read each, find redundancy
2. Plan target structure before touching anything
3. One file = one job, no exceptions
4. No data in two places — pick canonical location
5. Clean as you go — delete temp scripts immediately
6. Verify after every change

## When To Use

Any project where files are messy, redundant, or poorly organized.
