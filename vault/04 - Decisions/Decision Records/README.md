## How This Works

1. New decision → create `DEC-XXX - <Topic>.md` in `Active Decisions/`
2. Decision finalized → move to `Decision Records/`, mark LOCKED
3. Decision overturned → move to `Superseded/`, create new file
4. Each file records: what, why, what was rejected, consequence
