# DEC-004 — Drop Model

## Decision

**DROP 001 = THE DESCENT.** Each drop is a story chapter. The first drop tells
the descent — the fall of the guardians, broken halos, torn wings. Drop 002
(and beyond) continue the loop. No collabs until the foundation is proven.

## Context

The user explicitly locked the drop framework:
> "DROP 001 is the descent, and that's what we working for the story now."

The council debated whether to pursue collaborations early; the vote was to
build the foundation first.

## Rationale

- Story-driven drops create a reason to collect (loop = repeat purchase)
- The descent is the natural opening chapter (falling = the beginning)
- Collabs require leverage the brand doesn't have yet

## Options Considered

1. Early collab (rejected — no leverage, no foundation)
2. Static product line (rejected — no narrative pull)
3. **Story-chapter drops (accepted)** — each drop advances the lore

## Consequences

- Every drop needs narrative integration
- The 11:11 logo stays constant; only the chapter graphic changes
- Collection incentive: "complete the loop"

## Reversal Conditions

- If the story framework fails to move product, revisit the model
