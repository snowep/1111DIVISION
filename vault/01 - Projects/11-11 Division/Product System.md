# Product System

> How products are designed, priced, and released.
> Source: founding council production sessions.

## Drop 001 Product Spec (Locked)

| Spec | Value |
|------|-------|
| Garment | 16s Australian Coolbreeze Cotton |
| Weight | 235gsm |
| Vendor | Yogyakarta, Indonesia |
| MOQ | 15 pcs |
| Unit cost | ~Rp82,000 |
| Lead time | 2–3 weeks |
| Print | Screen print, white ink, vector-only |
| Retail | max Rp249k (239k–249k range) |

## Cost Model

```
Capital:                     Rp5,000,000
Production (15 × Rp82k):     Rp1,230,000
Remaining (ops/marketing):   ~Rp3,770,000

Margin at 249k:              ~67% gross
```

## Print Rules

- Vector only, max 4 colors, A3 max
- Minimum line weight 2–3pt
- White ink on black (current system)
- Sample proof before full run

## Constraints

- Capital limits production to one MOQ run — no rework budget
- Design error at print = 15 unusable shirts
- Cultural safety test required before production (DEC-007)
