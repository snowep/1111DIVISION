# Visual Identity

> Logo, typography, color, graphic language.
> Source: founding council design sessions.

## Brand Mark

- **11:11 wordmark forms a subtle cross** — the primary brand symbol (front/chest)
- Left 11 and right 11 subtly differentiated
- Opening/closing marks refined smaller (council review)
- Chest placement: mid-chest

## Drop 001 Back Print (Locked Spec)

- Circle 10cm diameter + crosshair through center
- Break at 45° (imperfection)
- Line weight 3pt bold
- Text: Plus Jakarta Sans Mono — 8pt specs / 14pt brand name, white (#FFFFFF)
- Text block: UNIT / STATUS / ORIGIN / FUNCTION / LOOP / TIMECODE
- Placement: center back, 10cm below collar, ~25cm total height

## Eye + Clock (Foundation Imagery)

- Single abstract minimal eye, pupil = clock at 11:11
- No triangle, no rays, no secondary clock
- 2–3pt line weight, A3 max, white on black
- Repeatable across future drops

## Typography

| Use | Typeface |
|-----|----------|
| Logo | Söhne (free font) |
| Back print brand name | Plus Jakarta Sans Mono 14pt |
| Back print specs | Plus Jakarta Sans Mono 8pt |

## Color

- Base: black tees (#0A0A0A)
- Ink: white (#FFFFFF)
- Minimal system — the symbol speaks, not the color
