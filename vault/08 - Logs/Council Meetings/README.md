## Lifecycle

```
MEETING → POSITION → CONFLICT → VOTE → SYNTHESIS → DECISION → MEMORY
```

## How This Works

1. Council convenes on a question
2. Each seat takes a position
3. Conflicts are identified
4. Vote is recorded
5. JARVIS synthesizes
6. Decision is linked to DEC-XXX record
7. Meeting becomes permanent knowledge
