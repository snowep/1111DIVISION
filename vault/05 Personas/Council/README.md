# Council

> The council is a multi-persona advisory system for 11:11 DIVISION.

## Structure

- **Fixed seats** (4): Permanent members, cannot be removed
- **Rotating seats** (3): Elected, can be eliminated
- **Reserved seats** (2): Future advisor, community representative
- **Spectators** (5): Former members or observers

## This File

This is the **knowledge layer** — what the human and JARVIS know about the council.

- **Canonical configuration** → `/council/` (source of truth)
- **Operational state** → `/.jarvis/council/` (what the council is doing now)
- **Knowledge** → this file (what the human knows about the council)
