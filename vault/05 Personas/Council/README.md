# Council Overview

> The Supreme Council — an 11-seat elite advisory board that founded and scales
> 11:11 DIVISION. Source: `historical chat.json` (founding constitution),
> `chat-Council of Creators.txt` (215 sessions).

## Structure

- **11 seats total**
- **4 Permanent** — fixed members, never rotate
- **7 Temporary** — nominated 2 each by permanent members (8 nominees),
  debated, voted; 1 eliminated → 7 seated

## Temporary Seats

> Rotate. 7 seated per phase. Nominated by permanent members relevant to the
> **current brand phase**. Debated → voted → seated. Underperformers are warned:
> "One more session like this, you're in spectator row."

## Operating Rules

1. **Each council session has ONE question** — the council answers it
2. Every member must give an **individual analysis** before any vote
3. Voters state: **position + confidence + evidence count + reasoning**
4. **Steve gives the final word** — synthesis, not veto
5. Recommendation is **advisory** — the user decides
6. Cultural safety: **Manado local test** for any design with spiritual/occult risk
7. **Lore is subtle** — never explicit bibles/religion in product
8. Sessions produce: evidence registry, positions, cross-examination,
   agreement classification, synthesis, recommendation (council protocol v2)

## Session Outputs

Each session generates structured artifacts (see `.jarvis/council/`):
- meeting record (question, participants, type)
- evidence registry (every claim traced)
- positions (per persona: vote + confidence + reasoning + conditions)
- cross-examination (conflicts + resolution options)
- agreement classification (full/qualified/partial/disagreement/abstention)
- synthesis (JARVIS integrated view)
- recommendation (candidate → user confirms → decision)
