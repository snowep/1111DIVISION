# Indexes

> Machine-readable indexes for fast lookup.

## Available Indexes

| Index | Purpose |
|-------|---------|
| `files.md` | File locations and metadata |
| `memories.md` | Memory entries with IDs |
| `skills.md` | Skill registry |
| `personas.md` | Persona registry |
| `decisions.md` | Decision registry |

## Rule

Indexes are maintained by JARVIS. They are machine-readable pointers, not knowledge.
