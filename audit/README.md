# Audit

> Execution history. Every command, every file change, every tool call.
>
> JARVIS distills important outcomes into vault/. This is the trail, not the knowledge.

## Purpose

- Record every operation JARVIS performs
- Allow forensic analysis when something goes wrong
- Provide evidence for decision validation

## Rule

Audit logs are append-only. Never delete. JARVIS references audit when validating past actions.
